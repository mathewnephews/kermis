# kermis
8bit game

## HTML games

Three browser versions, each a single self-contained file (pixel art, fonts and the "Beat The Clown" soundtrack built in). Open one in any browser or play them on GitHub Pages:

- [GAZZOLEEN](https://mathewnephews.github.io/kermis/games/gazzoleen.html) — Space Invaders style: pie the band before they reach the midway, hiding behind the rides. Hit the bear balloon for double pies.
- [Clown Run (vertical)](https://mathewnephews.github.io/kermis/games/clown-run-vertical.html) — time attack scroller: pie all band members as fast as you can. One more band member every level.
- [Clown Run (horizontal)](https://mathewnephews.github.io/kermis/games/clown-run-horizontal.html) — the same run as a side-scroller.

Controls: arrow keys or WASD to move, Space to throw, X for a super pie (Clown Run), P to pause, M for music. On phones, on-screen buttons appear.
